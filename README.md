# barid_bank_systeme
**Banque Barid Bank – Tableau de bord de gestion bancaire**

Ce projet consiste à concevoir et développer une interface web de gestion bancaire permettant de centraliser et de visualiser différentes opérations et informations financières.

Le tableau de bord offre une vue globale sur plusieurs fonctionnalités, notamment la gestion des mandats, les paiements Barid Pay, la comptabilité, le suivi des réclamations et la génération de rapports.

L'objectif de ce projet est de faciliter le suivi des activités bancaires, d'améliorer l'organisation des informations et de proposer une interface intuitive permettant une meilleure visualisation des données financières.

**Compétences développées :** développement web, conception d'interfaces utilisateur, organisation des données et création de tableaux de bord interactifs.
